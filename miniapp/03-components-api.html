🟢 第 3 章 · 组件与基础 API ​

本章信息

难度：🟢 入门 · 预计学习 50 分钟 · 前置：第 2 章 · WXML、WXSS 与生命周期

🎯 学习目标 ​

读完本章，你将能够：

  • 能认得并使用 view、text、image、button、scroll-view 五个高频组件
  • 能用 bindtap 处理点击事件，用 dataset 传值
  • 能在 navigateTo、redirectTo、switchTab 里选对路由 API
  • 能用 showToast、showModal 给用户反馈
  • 能用同步存储 API 存取本地数据

📇 术语卡 ​

术语白话解释
组件官方造好的「现成零件」，写个标签就能用
事件绑定告诉某个标签「被点了就叫这个函数」
dataset从标签上带数据进事件函数的通道，属性写成 data-xxx
页面栈你翻过的页面叠成的一摞，最多 10 层
tabBar 页底部导航栏指向的页面，只能用 switchTab 跳转
Toast屏幕中间一闪而过的小提示
模态框带「确定 / 取消」按钮、必须回应的弹窗
本地缓存存在用户手机上的小仓库，关掉小程序也还在

组件用途一句话记忆

👆 事件绑定 bindtap ​

bindtap 就是给标签装上「耳朵」：被点了，就去 js 里喊同名方法。示例项目首页就是这么写的：

wxml
<view class="container">
  <view class="title">你好，{{ userName }}！</view>
  <view class="desc">当前时间：{{ now }}</view>
  <button type="primary" bindtap="addCount">点我 +1（已点 {{ count }} 次）</button>
  <button bindtap="goLogs" class="mt">查看启动日志</button>
</view>

js
const { formatTime } = require('../../utils/util')
const app = getApp()

Page({
  data: {
    userName: '',
    count: 0,
    now: ''
  },
  onLoad() {
    this.setData({
      userName: app.globalData.userName,
      now: formatTime(new Date())
    })
  },
  onShow() {
    console.log('Index onShow')
  },
  addCount() {
    // 按钮被点时执行：更新数据，页面自动刷新
    this.setData({ count: this.data.count + 1 })
  },
  goLogs() {
    wx.navigateTo({ url: '/pages/logs/logs' })
  }
})

🧭 路由 API 三兄弟 ​

API效果白话记忆
wx.navigateTo保留当前页再盖一页，能返回翻一本新书
wx.redirectTo关掉当前页再跳，不能返回撕掉当前页
wx.switchTab跳到 tabBar 页（只能跳 tab 页）按底部导航
js
wx.navigateTo({ url: '/pages/logs/logs' })      // 保留当前页，可返回
wx.redirectTo({ url: '/pages/result/result' })  // 替换当前页
wx.switchTab({ url: '/pages/index/index' })     // 跳 tabBar 页专用
1
2
3

注意

url 必须是在 app.json 里注册过的页面路径；navigateTo 跳不了 tabBar 页，会直接报错。页面栈最多 10 层，超了也报错。

💬 交互反馈：Toast 与 Modal ​

js
// 轻提示：一闪而过，适合「操作成功」
wx.showToast({ title: '保存成功', icon: 'success' })

// 模态框：必须点按钮才能关，适合「危险操作确认」
wx.showModal({
  title: '确认删除',
  content: '删了就找不回来了哦',
  success(res) {
    if (res.confirm) console.log('用户点了确定')
    if (res.cancel) console.log('用户点了取消')
  }
})

💾 本地存储 ​

四个同步 API，名字直白：存、取、删、清。同步的意思是这一行干完才走下一行，写起来最省心：

API作用
wx.setStorageSync(key, value)存
wx.getStorageSync(key)取，不存在返回空字符串
wx.removeStorageSync(key)删某一个
wx.clearStorageSync()全清

示例项目用它记录启动日志——app.js 存，日志页取：

js
onLaunch() {
  const logs = wx.getStorageSync('launch_logs') || []
  logs.unshift(Date.now())
  wx.setStorageSync('launch_logs', logs.slice(0, 10))
}

💻 动手实践：给首页加「弹窗 + 存储」 ​

在 examples/native-demo 首页基础上追加两个按钮，一个发反馈、一个动存储：

wxml
<button type="warn" bindtap="clearLogs" class="mt">清空启动日志</button>
<button bindtap="sayHi" class="mt">打个招呼</button>
1
2
js
clearLogs() {
  wx.showModal({
    title: '确认清空',
    content: '启动日志将被删掉',
    success: (res) => {
      if (res.confirm) {
        wx.removeStorageSync('launch_logs')
        wx.showToast({ title: '已清空', icon: 'success' })
      }
    }
  })
},
sayHi() {
  wx.showToast({ title: '你好呀', icon: 'none' })
}

从零运行步骤：

  1. 打开开发者工具，导入 examples/native-demo（AppID 选测试号）
  2. 按上面代码在 pages/index/index.wxml 末尾追加两个按钮，在 pages/index/index.js 里追加两个方法，保存

  4. 点「打个招呼」
  5. ✅ 你应该看到： 屏幕中央弹出「你好呀」小提示并自动消失
  6. 点「清空启动日志」，在弹窗里点「确定」

✏️ 分级练习 ​

  1. 🟢 跟做型：加一个按钮，点击时把当前时间存进 storage（key 用 my_time），并用 console.log 打印出来。
  2. 🟡 修改型：把 sayHi 改成 showModal，带确定和取消按钮；点确定时再弹一个 Toast「很高兴认识你」。
  3. 🔴 创作型：给一个 view 挂 data-goods-id，点击后带着商品 id 跳转到日志页，并把 id 存入 storage（提示：url 后面可以用 ?id=xx 传参，第 2 章的 onLoad 参数会接住它）。

⚠️ 常见坑 ​

  • 点按钮毫无反应 → bindtap 的方法名和 js 里对不上，或方法误写进了 data 里 → 方法必须写在 Page({}) 第一层，逐字核对拼写
  • 报 can not navigate to a tabbar page → 用 navigateTo 跳了 tabBar 页面 → tabBar 页只能用 wx.switchTab
  • 连跳几页后报 navigateTo:fail webview count limit exceed → 页面栈超过 10 层 → 改用 redirectTo 替换当前页，或用 wx.navigateBack 返回
  • getStorageSync 拿到空字符串 → 存和取的 key 拼写不一致（如 log 和 logs） → 统一 key 命名，建议在文件顶部定义成常量

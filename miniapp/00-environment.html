  • 能安装并打开微信开发者工具（选对稳定版）

🧰 安装微信开发者工具 ​

小程序的一切开发都从它开始，第一个装它。

第 1 步：打开官网下载页

浏览器访问官方文档的下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

✅ 你应该看到： 标题为「微信开发者工具下载」的页面，上面有 稳定版 Stable Build 和 开发版 Nightly Build 两条通道。

第 2 步：选「稳定版 Stable Build」

新手永远选稳定版，Nightly 是尝鲜版，可能不稳定。按系统下载对应安装包（macOS 的 Apple 芯片选 ARM64 版）。

✅ 你应该看到： 页面列出以 1.06.xxxx 开头的版本号，点击后开始下载一个一百多 MB 的安装包。

第 3 步：安装

Windows 双击 exe 一路「下一步」；macOS 打开 dmg，把图标拖进 Applications。

✅ 你应该看到： 桌面出现紫色图标的「微信开发者工具」，双击打开后弹出微信扫码登录的二维码。

第 4 步：扫码登录

用你自己的微信扫码并确认登录。

✅ 你应该看到： 进入「项目列表」页面，中间有一个大大的 + 号。到这里工具就绪。

注意

安装路径和以后的项目路径，都建议只用英文和数字。中文路径是大量灵异报错的源头。

🌐 安装 Node.js（LTS 版） ​

第 1 步：打开官网

浏览器访问 https://nodejs.org，首页直接摆着两个绿色大按钮。

✅ 你应该看到： 左边按钮写着 LTS（带「推荐」字样），右边写着 Current。点左边的 LTS。

第 2 步：下载安装

双击安装包，Windows 一路「下一步」，macOS 一路「继续」，输密码确认。

第 3 步：验证安装

打开终端（Windows 按 Win + R 输入 cmd 回车；macOS 打开「终端」App），输入：

bash
node -v
1

✅ 你应该看到： 输出版本号，形如 v20.19.0（数字不同没关系，v 开头就是装好了）。再输入 npm -v，看到 10.x.x 一类的数字同样成功。

注意

如果提示 'node' 不是内部或外部命令（Windows）或 command not found: node（Mac），多半是装完没重开终端，环境变量还没生效。关掉终端窗口重新打开再试。

📝 安装 VS Code 与推荐插件 ​

第 1 步：安装 VS Code

访问 https://code.visualstudio.com 下载安装，过程同上。

✅ 你应该看到： 打开后是蓝色图标、左侧一列竖排小图标的编辑器窗口。

第 2 步：装 3 个插件

点左侧「扩展」图标（四个方块），逐个搜索并安装：

插件作用
minapp让 VS Code 认识 wxml、wxss，提供高亮和补全
Prettier保存时自动把代码排整齐
Chinese (Simplified)界面变中文（英文没压力可跳过）

✅ 你应该看到： 每个插件卡片上的「安装」按钮变成灰色的「已安装」。

为什么要装 VS Code？

开发者工具自带的编辑器前期完全够用；VS Code 打开大项目更快、插件更强。两者可以随时切换，文件是同一份。

📦 JavaScript 最小知识包 ​

小程序的逻辑层用 JavaScript 写。下面 5 个概念只讲小程序用到的部分，每个配一个 5 行内的小例子。

1. let 和 const：装值的盒子 ​

js
let score = 60          // 会变的值，用 let
const name = '小码'     // 不变的值，用 const
score = 95              // 合法，盒子里的值换成了 95
// name = '阿程'        // 报错！const 的盒子不许再装别的

记住一句话：默认写 const，确实要变才写 let。

2. 函数：把一段活打包 ​

js
function add(a, b) {
  return a + b          // return 把结果交出去
}
const sum = add(1, 2)   // 喊名字就执行，sum 是 3

3. 对象：带标签的卡片 ​

js
const user = { name: '小码', age: 18 }
console.log(user.name)  // 小码（点号取标签对应的值）
user.age = 19           // 点号也能改值

小程序里最常见的 Page({ data: {...} })，那个 data 就是个对象。

4. 数组：一排按编号取的盒子 ​

js
const todos = ['买牛奶', '写作业', '跑步']
console.log(todos[0])     // 买牛奶（下标从 0 开始）
console.log(todos.length) // 3（一共几个）

页面上能滚动的列表，背后就是一个数组。

5. 回调函数：干完活了叫我 ​

把一个函数当参数传出去，约定「事情办完再执行它」：

js
setTimeout(function () {
  console.log('一秒到了！')
}, 1000)  // 1000 毫秒后，花括号里的代码才执行

💻 动手实践：跑通第一个 JS 文件 ​

js
// hello.js —— 第 0 章验收作业，把 5 个概念串起来
const name = '小码'                          // const
let count = 0                                // let
function addOne(n) {                         // 函数
  return n + 1
}
const hobbies = ['写代码', '打篮球']         // 数组
const me = { name: name, likes: hobbies }    // 对象

count = addOne(count)

setTimeout(() => {                           // 回调函数
  console.log(me.name + ' 学会了第 ' + count + ' 个知识点')
}, 1000)

从零运行步骤：

  1. 新建一个文件夹 miniapp-practice（纯英文路径）
  2. 用 VS Code 打开它，新建文件 hello.js，粘贴上面代码并保存（Ctrl / Cmd + S）
  3. VS Code 顶部菜单点「终端 → 新建终端」
  4. 在终端输入 node hello.js 并回车
  5. ✅ 你应该看到： 终端安静约一秒后，打印出 小码 学会了第 1 个知识点

✏️ 分级练习 ​

  1. 🟢 跟做型：把 hello.js 里的 count = addOne(count) 改成连续调用三次，让输出变成「第 3 个知识点」。
  2. 🟡 修改型：给 me 对象再加一个标签（比如 city），并把它拼进最后打印的那句话里。
  3. 🔴 创作型：写一个 pick(arr) 函数，传入数组，随机返回其中一项（提示：Math.random() 乘上 arr.length 再取整）。

⚠️ 常见坑 ​

  • 'node' 不是内部或外部命令 / command not found: node → 装完 Node 没重开终端，环境变量没生效 → 关掉所有终端窗口（保险起见重启电脑）再输 node -v
  • 官网下载特别慢或失败 → 官方 CDN 波动 → 换个时段或换网络重试，开发者工具优先走「稳定版」通道
  • 装成了 Nightly 版，界面功能天天变 → 新手只需要稳定版 → 回下载页选「稳定版 Stable Build」重装
  • 项目放在带中文/空格的文件夹里，后续各种打不开 → 中文路径是重灾区 → 从现在起所有代码目录只用英文

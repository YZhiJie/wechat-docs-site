🟢 第 1 章 · 注册与工具链 ​

本章信息

难度：🟢 入门 · 预计学习 40 分钟 · 前置：第 0 章 · 环境搭建

🎯 学习目标 ​

读完本章，你将能够：

  • 能独立注册一个个人主体的小程序账号
  • 能在后台找到并保存自己的 AppID
  • 能说出开发者工具三大区域各管什么
  • 能用测试号新建项目，跑出第一个 Hello World

📇 术语卡 ​

术语白话解释
小程序账号小程序的「户口」，在微信公众平台注册，主体分个人、企业等
AppID小程序的身份证号，wx 开头的一串字符，每个小程序唯一
测试号官方发的「临时身份证」，不用注册也能建项目跑代码
模拟器编辑器左侧的手机屏幕「替身」，编译后立刻在这里看效果
编辑器中间写代码的区域，左边文件树、右边代码
调试器右侧查问题的区域，Console 看日志、WXML 看结构
编译把你写的源码「现场加工」成模拟器能跑的程序
真机调试用自己的手机扫码，在真手机上看效果和日志

🧾 注册小程序账号（个人主体） ​

第 1 步：进入注册入口

浏览器打开 https://mp.weixin.qq.com，点右上角「立即注册」。

✅ 你应该看到： 一个大页面摆着几种账号类型卡片：订阅号、服务号、小程序、企业微信等。

第 2 步：选「小程序」并填写邮箱

点「小程序」卡片，填写邮箱、密码、验证码。邮箱必须是没注册过公众平台（公众号/小程序）的。勾选同意协议后提交。

✅ 你应该看到： 提示「邮件已发送」，去这个邮箱收件箱里找到激活邮件，点击里面的链接完成激活。

第 3 步：选主体类型「个人」

激活后回到注册页，选择主体类型。个人学习就选个人（不需要营业执照）。

✅ 你应该看到： 进入「信息登记」页，要求填写管理员身份信息。

第 4 步：信息登记与扫码验证

填写管理员姓名、身份证号，用管理员本人微信扫码验证，填手机验证码确认。

✅ 你应该看到： 提示「注册完成」，页面跳转进入小程序管理后台（绿色的管理界面）。

注意

个人主体的小程序不能开通微信支付、不能使用部分高级接口（如获取用户手机号），web-view 打开外部网页也受限。但学习开发完全够用。

🔑 获取 AppID ​

第 1 步：进入开发设置

登录 https://mp.weixin.qq.com，左侧菜单点「管理 → 开发管理」，顶部切到「开发设置」。

第 2 步：复制 AppID

找到「AppID(小程序ID)」一行，形如 wx1234567890abcdef，点「复制」存进备忘录。

✅ 你应该看到： AppID 是一串 wx 开头共 18 位的字符，旁边还能看到 AppSecret（学习阶段先不用管，也别发给任何人）。

🗺️ 开发者工具界面导览 ​

打开微信开发者工具扫码登录后，随便进入一个项目（下一节就会建），记住三大区域：

区域位置干什么
模拟器左侧一台虚拟手机，代码改完点「编译」立刻看到效果
编辑器中间写代码：左边目录树，右边文件内容
调试器右侧查问题：Console 看日志和报错，WXML 面板看页面结构

顶部工具栏最常用三个按钮：编译（重新运行）、预览（生成二维码用手机扫码看）、真机调试（手机上看还能传日志）。

✅ 你应该看到： 三个区域从左到右一字排开；如果模拟器没显示，点工具栏右侧的「模拟器」图标把它勾上。

🚀 新建第一个项目（用测试号） ​

第 1 步：新建

回到项目列表页，点中间的 + 号。

第 2 步：填四样信息

  • 项目名称：随便起，如 hello-mini
  • 目录：选一个新建的空文件夹（纯英文路径）
  • AppID：点「测试号」（没有正式账号也能跑；有就填上章复制的 AppID）
  • 开发模式：小程序，后端服务选「不使用云服务」（云开发到第 8 章才用）

第 3 步：选模板并确定

模板选「JavaScript - 基础模板」，点「确定」。

✅ 你应该看到： 进度条跑完，模拟器里出现一个带头像、昵称和「Hello World」字样的页面，Console 没有红色报错。

第 4 步：改出你的第一句话

在编辑器里按 Ctrl / Cmd + F 搜索 Hello World，把这段文字改成 小码的第一个小程序，保存（Ctrl / Cmd + S）。

✅ 你应该看到： 模拟器自动重新编译，那句问候变成了你写的话——恭喜，这就是改代码 → 看效果的完整闭环。

🗂️ 模板项目的目录速览 ​

在编辑器左侧文件树里看一眼，模板已经帮你搭好了骨架：

方式 B：导入本书配套示例工程

教程仓库里的 examples/native-demo 是贯穿全书的示例项目。操作：项目列表点 + 号 → 目录选择该文件夹 → AppID 选「测试号」→ 确定。导入后按下面清单逐条验收：

  • 首页出现「你好，小码！」和当前时间
  • 点「点我 +1」按钮，数字从 0 递增
  • 点「查看启动日志」，跳转到日志页看到时间列表
  • 点「编译」重新运行后，日志页多出一条新记录
  • 调试器 Console 没有红色报错

从零运行步骤（方式 B）：

  1. 在微信开发者工具首页点 + 号
  2. 目录选择 examples/native-demo 文件夹，AppID 选「测试号」，后端服务选「不使用云服务」
  3. 点「确定」，等待编译完成
  4. ✅ 你应该看到： 模拟器显示「你好，小码！」页面
  5. 按上面 5 条清单逐项操作验证
  6. ✅ 你应该看到： 清单全部打勾，说明环境与工具链完全就绪

✏️ 分级练习 ​

  1. 🟢 跟做型：把首页问候语改成你的名字，再打开根目录的 app.json，把 navigationBarTitleText 改成「我的地盘」，观察模拟器顶部标题变化。
  2. 🟡 修改型：在首页问候语下方自己加一行新文字（仿照现有结构多写一个 view 标签），内容随意。
  3. 🔴 创作型：打开调试器的「WXML」面板，找到你新加的那行文字对应的节点并点它，观察模拟器高亮——体验「页面结构可以被审查」。

⚠️ 常见坑 ​

  • 注册时提示「该邮箱已被占用」 → 邮箱注册过公众号或被微信生态绑定 → 换一个从没用过的邮箱
  • Console 报 invalid appid，模拟器白屏 → AppID 复制时带了空格或填错 → 重新完整复制，注意结尾别带空格
  • 新建项目点「确定」没反应或提示「目录非空」 → 所选文件夹里有旧文件 → 换一个全新的空文件夹
  • 测试号项目里调用某些接口提示无权限 → 测试号能力有限制 → 正式注册的 AppID 才有完整能力

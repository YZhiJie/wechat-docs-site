🟡 第 4 章 · JSSDK：分享、支付与定位 ​

本章信息

难度：🟡 进阶 · 预计学习 50 分钟 · 前置：第 3 章 · 网页授权（OAuth）

🎯 学习目标 ​

读完本章，你将能够：

  • 能说出 JSSDK 都能做什么、为什么需要「签名」
  • 能手写 jsapi_ticket → 签名字符串 → sha1 的完整签名算法（Node.js）
  • 能在网页里正确注入 wx.config 并通过校验
  • 能实现自定义分享与网页定位，并说清微信支付的前置条件

📇 术语卡 ​

术语白话解释
JSSDK微信注入网页的「能力包」，让 H5 能调起分享、定位、扫码等原生能力
jsapi_ticket计算 JSSDK 签名用的「临时凭证」，同样要缓存（7200 秒过期，以官方文档为准）
noncestr随机字符串，签名四要素之一，防止签名被重放
timestamp秒级时间戳，签名四要素之一
签名用 ticket + 三要素算出的一串 sha1 值，证明「这个网页是我域名下的正经页面」
wx.config前端注入签名的函数，校验通过后 wx 对象的能力才会解锁
jsApiList本次要用的能力清单，没列进去的接口调用会失败
商户号微信支付商户平台的账号（mch_id），做支付的前置条件，个人主体无法开通

🧰 JSSDK 能做什么 ​

能力接口举例备注
自定义分享updateAppMessageShareData / updateTimelineShareData本章实战
网页定位getLocation本章实战，需在后台开通相关权限
拍照 / 选图chooseImage常见表单场景
扫码scanQRCode商品识别等场景
录音startRecord 等语音类应用
微信支付chooseWXPay需要商户号，本文只讲流程

完整能力列表以官方「JSSDK 说明文档」为准。原理一句话：微信往网页里注入一个 wx 对象，但你得先用签名证明这个网页是配在「JS 接口安全域名」下的合法页面，wx 才肯干活。

注意

JSSDK 的「JS 接口安全域名」在后台「设置与开发 → 公众号设置 → 功能设置」里配置，要求备案域名（测试号可直接填内网穿透域名）。域名每月可修改次数有限，以官方文档为准。

✍️ 签名算法：三步算出 signature ​

第 1 步：用 access_token 换 jsapi_ticket

bash
curl "https://api.weixin.qq.com/cgi-bin/ticket/getticket?access_token=你的access_token&type=jsapi"
1

✅ 你应该看到： 返回 {"errcode":0,"errmsg":"ok","ticket":"sAI4C...","expires_in":7200}。这里的 access_token 是第 2 章 cgi-bin 那把，不是 OAuth 的。ticket 也要缓存，原因同 token（限额以官方文档为准）。

第 2 步：拼签名字符串（四要素，顺序固定）

text
jsapi_ticket=TICKET&noncestr=NONCESTR&timestamp=TIMESTAMP&url=URL
1
  • 顺序固定为 jsapi_ticket、noncestr、timestamp、url，用 & 直连，所有值不做 URL 编码
  • url = 当前网页地址去掉 # 及其后面部分（含 query 参数）
  • timestamp 秒级、noncestr 随机串

第 3 步：对整串做 sha1

得到的 40 位十六进制字符串就是 signature。

注意

签名算错九成栽在 url 上：签名用的 url 必须和最终调用 wx.config 的页面地址完全一致（包括参数、包括有无 80/443 端口、绝不带 # 后缀）。前端要把地址传给后端算签名，别在两边各拼一遍。

💻 动手实践：签名服务 + 分享定位网页 ​

后端：get-signature.js（零依赖，Node 18+） ​

js
// get-signature.js —— jsapi_ticket 缓存 + sha1 签名 + HTTP 服务
const http = require('http')
const crypto = require('crypto')

const APPID = '你的AppID或测试号appid'
const SECRET = '你的Secret或测试号secret'

// ---- 第 1 步：access_token 与 ticket 都做缓存 ----
let tokenCache = { token: '', expireAt: 0 }
let ticketCache = { ticket: '', expireAt: 0 }

async function getToken() {
  if (tokenCache.token && Date.now() < tokenCache.expireAt) return tokenCache.token
  const url = 'https://api.weixin.qq.com/cgi-bin/token?grant_type=client_credential&appid=' + APPID + '&secret=' + SECRET
  const data = await (await fetch(url)).json()
  if (!data.access_token) throw new Error('换 token 失败：' + JSON.stringify(data))
  tokenCache = { token: data.access_token, expireAt: Date.now() + (data.expires_in - 300) * 1000 }
  return tokenCache.token
}

async function getTicket() {
  if (ticketCache.ticket && Date.now() < ticketCache.expireAt) return ticketCache.ticket
  const token = await getToken()
  const url = 'https://api.weixin.qq.com/cgi-bin/ticket/getticket?access_token=' + token + '&type=jsapi'
  const data = await (await fetch(url)).json()
  if (!data.ticket) throw new Error('换 ticket 失败：' + JSON.stringify(data))
  ticketCache = { ticket: data.ticket, expireAt: Date.now() + (data.expires_in - 300) * 1000 }
  return ticketCache.ticket
}

// ---- 第 2、3 步：拼签名字符串，做 sha1 ----
async function getSignature(pageUrl) {
  const ticket = await getTicket()
  const noncestr = Math.random().toString(36).slice(2, 18)
  const timestamp = Math.floor(Date.now() / 1000)
  const raw = 'jsapi_ticket=' + ticket + '&noncestr=' + noncestr +
    '&timestamp=' + timestamp + '&url=' + pageUrl
  const signature = crypto.createHash('sha1').update(raw).digest('hex')
  return { appId: APPID, timestamp, noncestr, signature }
}

http.createServer(async (req, res) => {
  const u = new URL(req.url, 'http://localhost')
  if (u.pathname === '/jssdk-sign') {
    // 前端传来的当前页地址（已去掉 # 后缀）
    const pageUrl = u.searchParams.get('url')
    if (!pageUrl) { res.end('缺少 url 参数'); return }
    const conf = await getSignature(pageUrl)
    res.writeHead(200, { 'Content-Type': 'application/json; charset=utf-8' })
    res.end(JSON.stringify(conf))
    return
  }
  res.writeHead(200, { 'Content-Type': 'text/html; charset=utf-8' })
  res.end(indexHtml)
}).listen(3000, () => console.log('已启动：http://localhost:3000'))

// ---- 前端页面（第 5 步会用到的 wx.config 就写在这里） ----
const indexHtml = [
  '<script src="https://res.wx.qq.com/open/js/jweixin-1.6.0.js"></script>',
  '<h1>JSSDK 演示页</h1><p id="tip">正在注入 config……</p><p id="loc"></p>',
  '<script>',
  '  var pageUrl = location.href.split("#")[0]', // 签名用的 url：无 # 后缀
  '  fetch("/jssdk-sign?url=" + encodeURIComponent(pageUrl))',
  '    .then(function (r) { return r.json() })',
  '    .then(function (conf) {',
  '      wx.config({',
  '        debug: true, // 真机会弹出 config:ok 提示，方便排查',
  '        appId: conf.appId,',
  '        timestamp: conf.timestamp,',
  '        nonceStr: conf.noncestr,',
  '        signature: conf.signature,',
  '        jsApiList: ["updateAppMessageShareData", "updateTimelineShareData", "getLocation"]',
  '      })',
  '      wx.ready(function () {',
  '        document.getElementById("tip").textContent = "config 成功，能力已解锁"',
  '        // 自定义分享内容',
  '        wx.updateAppMessageShareData({',
  '          title: "小码的签到小站", desc: "跟着教程做出的第一个分享卡片",',
  '          link: pageUrl, imgUrl: "https://example.com/logo.png"',
  '        })',
  '        wx.updateTimelineShareData({ title: "小码的签到小站", link: pageUrl })',
  '        // 网页定位',
  '        wx.getLocation({',
  '          type: "wgs84",',
  '          success: function (res) {',
  '            document.getElementById("loc").textContent =',
  '              "你的位置：" + res.latitude + "，" + res.longitude',
  '          }',
  '        })',
  '      })',
  '      wx.error(function (err) {',
  '        document.getElementById("tip").textContent = "config 失败：" + err',
  '      })',
  '    })',
  '</script>'
].join('')

从零运行步骤：

  1. 在测试号沙盒页把隧道域名填入「JS 接口安全域名」（正式号在「功能设置」里配）
  2. 修改文件顶部常量，终端运行 node get-signature.js
  3. 手机微信打开 隧道域名/（页面会先请求签名，再注入 config）
  4. ✅ 你应该看到： 页面顶部弹出 config:ok 的调试提示（debug: true 的效果），提示文字变成「config 成功，能力已解锁」
  5. 点击右上角「···」→「发送给朋友」，✅ 分享卡片标题是「小码的签到小站」、描述是自定义文案
  6. 首次使用会弹「获取你的位置」授权框，✅ 同意后页面显示一串经纬度数字

💳 微信支付：只讲流程 ​

支付的前置条件是：认证服务号 + 微信商户号（mch_id），个人主体无法开通，所以本课程不实操。完整流程五步（细节以官方文档为准）：

  1. 用户在网页点「支付」→ 你的后端调用「统一下单」接口，拿到 prepay_id
  2. 后端按支付签名规则生成前端拉起参数
  3. 前端 wx.chooseWXPay(参数) 拉起支付收银台
  4. 用户付款后，微信异步回调你的后端 notify 地址
  5. 后端验签确认支付成功，再发货 / 更新订单（不要只信前端结果）

✏️ 分级练习 ​

  1. 🟢 跟做型：跑通签名服务，把 config:ok 与自定义分享卡片的截图记录下来。
  2. 🟡 修改型：把分享的 title、desc、imgUrl 换成你自己的内容；再把 jsApiList 里加上 scanQRCode 并写一个按钮调用它。
  3. 🔴 创作型：给 getLocation 加上 type: "gcj02"，并对照官方文档说明两种坐标系各自适用什么场景（如展示地图 vs 导航）。

⚠️ 常见坑 ​

  • wx.error 报 invalid signature → 签名用的 url 与当前页不一致（带了 # 后缀、少了参数、前端没 encodeURIComponent）→ 把前端 pageUrl 和后端收到的值都打印出来逐字符对比
  • config:fail, invalid url domain → 当前域名没配「JS 接口安全域名」或协议不符 → 后台重新核对配置；注意域名每月修改次数有限，以官方文档为准
  • 换 ticket 报 errcode: 40001, errmsg: "invalid credential" → 混用了 OAuth 的网页授权 token，或 token 过期 → 确认用的是 /cgi-bin/token 换来的票
  • config 显示 ok，但分享卡片还是旧的 → 分享接口调用时机早于 config 完成 → 所有 wx.updateXxxShareData 必须放进 wx.ready 回调里

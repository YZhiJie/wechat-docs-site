🟢 第 1 章 · 账号类型与认证 ​

本章信息

难度：🟢 入门 · 预计学习 30 分钟 · 前置：第 0 章 · 环境准备

🎯 学习目标 ​

读完本章，你将能够：

  • 能说出订阅号、服务号、企业微信、小程序的定位差异
  • 能判断个人主体能注册哪几种账号
  • 能说清认证前后接口能力的三档差异
  • 能在后台找到「接口权限」页，并安全地保管 AppID 与 AppSecret

📇 术语卡 ​

术语白话解释
主体注册时登记的「你是谁」：个人、企业、政府等，决定了你能开的账号类型
订阅号偏内容媒体的号，一天能群发一次，被折叠在「订阅号消息」文件夹里
服务号偏对外服务的号，一个月群发四次，直接躺在会话列表里，接口权限最多
企业微信面向企业内部员工办公协同的工具，不面向公众号粉丝
认证每年花一笔钱向微信证明「我是正规组织」，换来更多高级接口
接口权限后台里的一份「能力清单」，哪些接口能用、哪些不能用一目了然
AppID / AppSecret账号的「用户名 + 密钥」，调接口时的身份凭证，Secret 绝不能泄露

注意

表中群发次数、认证费用等数字会随官方政策调整，一律以官方文档和后台实际展示为准。做决策前去官方说明页核对一遍。

一分钟选出该注册哪种 ​

拿不准就用这三个问题过一遍：

  1. 每天想发文章吗？ 想做内容、日更推文 → 订阅号
  2. 要对外提供服务和支付吗？ 底部菜单跳转、模板通知、微信支付一个都不能少 → 认证服务号（需要组织资质）
  3. 只是给自己团队用？ 面向员工而非粉丝 → 企业微信；想做即点即用的工具 → 小程序

本课程走「公众号 H5 / 接口开发」路线，所以主角是订阅号 + 测试号的组合拳。

👤 个人主体能选什么 ​

拿着个人身份证，你能注册的是：

  • ✅ 订阅号（个人）——本课程的主角，学接口开发够用
  • ✅ 小程序（个人）——另一条课程线的主角
  • ❌ 服务号——仅组织可注册，个人没有入口
  • ❌ 企业微信——需要组织资质

个人订阅号权限少怎么办？ 公众平台提供了「测试号」（俗称沙盒）：在后台搜索「公众平台测试帐号」即可申请，它几乎开放全部接口（网页授权、模板消息、自定义菜单都有），不用认证、不用备案。后面学到权限不够的章节，就用测试号练手。

🔑 认证带来的接口差异 ​

账号能力大致分三档，越往上门槛越高：

档位能力举例谁有
基础能力自定义菜单、素材管理、被动回复消息所有公众号，不看认证
认证解锁获取用户基本信息、用户管理、部分高级接口认证后的订阅号 / 服务号
服务号专属网页授权 OAuth、JSSDK（分享 / 定位 / 支付）、模板消息、微信支付仅认证服务号

给零基础的你

个人订阅号没有网页授权和模板消息权限，这不是你操作错了。课程第 3、4、6 章会用测试号带你把流程完整跑一遍，学到的代码一模一样，将来换成认证服务号直接可用。

现在就申请一个测试号 ​

测试号（沙盒）是官方给开发者的「练号」，两分钟就能开通：

第 1 步：进入沙盒页

登录后台，在「设置与开发」里搜索或找到「公众平台测试帐号」，点击进入。

✅ 你应该看到： 一个朴素的测试号管理页，顶部显示测试号的 appID 和 appsecret，下方是「接口配置信息」「网页授权获取用户基本信息」等测试入口。

第 2 步：记录测试号凭证

把测试号的 appID、appsecret 抄进你的本地私密笔记——第 2 章起它们会替代正式号凭证出场。

第 3 步：扫码关注测试号

手机微信扫描沙盒页提供的二维码，关注这个测试号。

✅ 你应该看到： 沙盒页「用户列表」里出现你的微信昵称——从现在起，你就是这个测试号的第一个粉丝。

测试号无须认证、无须备案域名，几乎开放全部接口（限额另计，以官方文档为准），是后面五章的「主战场」。

注意

测试号仅用于开发调试，不要拿它对外提供服务或投放真实用户；正式功能必须迁移到认证后的正式账号。

认证怎么办理（概览） ​

将来有组织资质、要上正式项目时，认证流程大致三步（入口位置与所需材料以官方文档为准）：

第 1 步：进入认证入口

后台「设置与开发 → 微信认证」，点「开通」。

✅ 你应该看到： 认证向导页，列出所需材料（主体资质、对公账户、运营者信息等）。

第 2 步：填写资料并支付认证费

按向导上传材料、支付 300 元审核费（金额以官方文档为准）。

✅ 你应该看到： 支付成功页，状态变为「审核中」。

第 3 步：等待审核结果

第三方审核机构会在几个工作日内联系你核实（时限以官方文档为准）。

✅ 你应该看到： 后台认证状态变为「已认证」，接口权限页随之多出一批「已获得」。

注意

认证有费用且按年计费，未按时年审会失去对应接口权限。个人开发者学习阶段不必花这笔钱，用测试号即可。

🧾 接口权限页在哪里看 ​

第 1 步：登录后台

浏览器打开 https://mp.weixin.qq.com，扫码登录。

✅ 你应该看到： 公众号后台首页。

第 2 步：进入接口权限页

左侧菜单点「设置与开发」→「接口权限」（后台改版后路径可能微调，以实际界面为准）。

✅ 你应该看到： 一张长长的权限清单，每行一个能力（如「获取用户基本信息」「网页服务 → 网页授权」），右侧标注「已获得」或「未获得」。

第 3 步：看懂三列关键信息

  • 接口名称：能力叫什么
  • 状态：能不能用
  • 说明：有没有频次、场景限制（限额数字以官方文档为准）

第 4 步：拿到 AppID、保管 AppSecret

仍在「设置与开发」→「基本配置」页，能看到开发者 ID（AppID）；AppSecret 首次需要点「重置」生成，只显示一次。

✅ 你应该看到： AppSecret 出现在页面上。立刻把它存进本地私密文件或密码管理器，不要提交到代码仓库、不要发到聊天群。

注意

AppSecret 一旦泄露，别人可以冒用你的账号调所有接口。重置 Secret 会让旧的立即失效——已上线的服务会当场趴窝，正式项目重置前先想清楚。

💻 动手实践：盘点你的账号家底 ​

从零运行步骤：

  1. 登录公众号后台，进入「设置与开发 → 接口权限」
  2. 在清单里找到下面这几项，把状态抄进你的笔记：自定义菜单、网页授权、模板消息（或订阅通知）、获取用户基本信息、微信支付
  3. 再到「基本配置」页记下 AppID，重置并保存 AppSecret
  4. 对照下面的表格模板，填出你自己账号的「能力清单」：

✏️ 分级练习 ​

  1. 🟢 跟做型：进入接口权限页，抄录 5 个权限的名称和状态，感受一下「能力清单」长什么样。
  2. 🟡 修改型：朋友想做一个「到店预约 + 会员通知」的服务，对照四种账号的对比表，帮他选出该注册的账号类型，并写出三条理由。
  3. 🔴 创作型：申请一个公众平台测试号，把它的接口权限列表和你正式订阅号对比，列出 3 个「测试号有、正式号没有」的接口，写进笔记。

⚠️ 常见坑 ​

  • AppSecret 忘了保存就关了页面 → Secret 只显示一次，只能重置 → 重置后立刻存好；正式项目要先评估旧 token 失效影响
  • 个人订阅号找不到「网页授权」入口 → 权限本身不存在，不是你眼花 → 学习期用测试号（见练习 3），正式上线换认证服务号
  • 拿个人身份证注册服务号 → 服务号仅组织主体可注册 → 学习用订阅号，或以个体工商户等主体注册
  • 账号名称注册失败提示被占用 → 名称全局唯一 → 换一个更独特的名字，命名规则以官方文档为准

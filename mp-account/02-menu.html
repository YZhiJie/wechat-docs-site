🟢 第 2 章 · 自定义菜单 ​

本章信息

难度：🟢 入门 · 预计学习 45 分钟 · 前置：第 1 章 · 账号类型与认证

🎯 学习目标 ​

读完本章，你将能够：

  • 能说清 access_token 是什么、为什么必须缓存
  • 能写一个带过期管理的 access_token 缓存模块（Node.js）
  • 能用 curl 和 Node.js 两种方式创建自定义菜单
  • 能区分 click / view / miniprogram 三种菜单类型，并完成查询与删除

📇 术语卡 ​

术语白话解释
access_token调接口用的「临时门票」，2 小时过期，凭 AppID + AppSecret 去换
expires_in门票的有效秒数，一般为 7200（以官方文档为准）
缓存把用过的数据存起来复用，避免反复去换、浪费调用额度
请求体POST 请求里真正「装货」的部分，菜单 JSON 就放在这里
click 菜单点击后微信给你服务器发一条事件消息，由你决定怎么回应
view 菜单点击后直接在微信里打开一个网页链接
miniprogram 菜单点击后跳到指定小程序的指定页面
errcode微信接口返回的错误码，0 是成功，其他数字对应具体错误

🎫 access_token：公众号的「门票」 ​

从这一章起，咱们调的都是需要身份的接口。每次调用都要在地址上带一个 access_token，它相当于游乐场的门票：刷票进门，2 小时作废，过期再换。

第一步：先手动换一张票 ​

把下面的命令里的 AppID、AppSecret 换成你自己的（第 1 章拿到的那对）：

bash
curl "https://api.weixin.qq.com/cgi-bin/token?grant_type=client_credential&appid=你的AppID&secret=你的AppSecret"
1

✅ 你应该看到： 返回一段 JSON：{"access_token":"74_xxxxx...","expires_in":7200}。那串很长的字符就是门票，7200 是有效秒数（约 2 小时）。

第二步：理解为什么必须缓存 ​

两个原因，缺一不可：

  1. 有每日调用限额：获取 access_token 的接口每天有次数上限（具体数字以官方文档为准），每次用户请求都去换新票，额度很快见底
  2. 有效期 7200 秒：不记下过期时间，你会拿着一张「已作废」的票到处碰壁

所以正确姿势是：换到票就存起来，没过期就复用，快过期了才去换。

注意

调接口前，先去后台「设置与开发 → 基本配置 → IP 白名单」把你的出口 IP 加进去，否则换票接口会直接拒绝你（报错 40164，见文末常见坑）。

第三步：写出缓存模块 ​

js
// token.js —— access_token 统一管理，第 4、6、7 章都会复用
// 需要 Node.js 18 及以上（自带 fetch）
const APPID = '你的AppID'
const SECRET = '你的AppSecret'

// 缓存：一张票 + 过期时间戳
let cache = { token: '', expireAt: 0 }

async function getToken() {
  // 还没过期，直接用旧票
  if (cache.token && Date.now() < cache.expireAt) {
    return cache.token
  }
  // 过期了，去换一张新票
  const url =
    'https://api.weixin.qq.com/cgi-bin/token' +
    '?grant_type=client_credential' +
    '&appid=' + APPID +
    '&secret=' + SECRET
  const res = await fetch(url)
  const data = await res.json()
  if (!data.access_token) {
    // 40164 = IP 白名单，40001/40125 = 凭证错误，详见官方全局返回码说明
    throw new Error('获取 access_token 失败：' + JSON.stringify(data))
  }
  // 提前 300 秒过期，防止临界点拿着废票进不去
  cache = {
    token: data.access_token,
    expireAt: Date.now() + (data.expires_in - 300) * 1000
  }
  return cache.token
}

module.exports = { getToken }

🍽️ 创建自定义菜单 ​

菜单是一个 POST 请求，菜单结构放在请求体（JSON）里发给微信。

三种菜单类型 ​

类型关键字段用户点击后发生什么
clickkey（自定义标识）微信向你的服务器推送一条事件消息，你回复什么它就显示什么（第 5 章实现）
viewurl直接在微信内置浏览器打开这个网页
miniprogramappid + pagepath跳转到指定小程序的指定页面

菜单 JSON 长这样 ​

json
{
  "button": [
    { "type": "click", "name": "今日签到", "key": "DO_CHECKIN" },
    { "type": "view", "name": "关于我们", "url": "https://example.com/about" },
    {
      "name": "更多",
      "sub_button": [
        { "type": "view", "name": "帮助文档", "url": "https://example.com/help" }
      ]
    }
  ]
}

动手：curl 版与 Node.js 版 ​

把上面的 JSON 存成 menu.json，然后：

bash
curl -X POST "https://api.weixin.qq.com/cgi-bin/menu/create?access_token=你的access_token" \
  -d @menu.json

js
// create-menu.js —— 复用 token.js 自动拿票，不用手动粘 token
const { getToken } = require('./token')

const menu = {
  button: [
    { type: 'click', name: '今日签到', key: 'DO_CHECKIN' },
    { type: 'view', name: '关于我们', url: 'https://example.com/about' },
    {
      name: '更多',
      sub_button: [
        { type: 'view', name: '帮助文档', url: 'https://example.com/help' }
      ]
    }
  ]
}

async function main() {
  const token = await getToken()
  const url = 'https://api.weixin.qq.com/cgi-bin/menu/create?access_token=' + token
  const res = await fetch(url, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(menu)
  })
  const data = await res.json()
  console.log('创建结果：', JSON.stringify(data))
}

main()

🔍 查询与删除菜单 ​

查询当前菜单（看线上真实生效的结构）：

bash
curl "https://api.weixin.qq.com/cgi-bin/get_current_selfmenu_info?access_token=你的access_token"
1

✅ 你应该看到： 返回一段 JSON，is_menu_open 为 1，selfmenu_info 里是你刚创建的菜单树。

删除全部菜单：

js
// delete-menu.js
const { getToken } = require('./token')

async function main() {
  const token = await getToken()
  const url = 'https://api.weixin.qq.com/cgi-bin/menu/delete?access_token=' + token
  const data = await (await fetch(url, { method: 'GET' })).json()
  console.log('删除结果：', JSON.stringify(data))
}

main()

✏️ 分级练习 ​

  1. 🟢 跟做型：完整走一遍「换票 → 缓存 → 建菜单 → 手机上看效果」，把每个环节的输出截图或抄录下来。
  2. 🟡 修改型：在「更多」下面再加一个二级 view 菜单「联系我们」，重新运行 create-menu.js，验证旧菜单被整体覆盖。
  3. 🔴 创作型：写一个 query-menu.js 脚本调用查询接口，把返回的 JSON 用 JSON.stringify(data, null, 2) 格式化打印，对照 menu.json 检查结构是否一致。

⚠️ 常见坑 ​

  • errcode: 40164, errmsg: "invalid ip xx.xx.xx.xx ipv6 ::ffff:xx.xx.xx.xx, not in whitelist" → 你的出口 IP 不在白名单 → 后台「基本配置 → IP 白名单」添加该 IP；家庭宽带 IP 会变，报这个错先看提示里的 IP 是不是变了
  • errcode: 40013, errmsg: "invalid appid" → AppID 填错（带了空格、误填成 AppSecret）→ 回基本配置页重新复制
  • errcode: 40125, errmsg: "invalid appsecret" → Secret 被重置过或复制不完整 → 后台重置后同步更新 token.js 里的常量
  • 创建返回 ok，手机上却看不到菜单 → 微信客户端有缓存 → 退出会话重进、取消关注再关注，或等几分钟再试

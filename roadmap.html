🗺️ 学习路线图 ​

我该从哪开始？三问自测

  1. 你会编程吗？ 完全不会 → 从对应方向的第 0 章开始，不要跳过；会一点 JS → 可快速翻完第 0 章
  2. 你的目标是什么？ 做小程序 → 走「小程序线」；做公众号 H5 / 接口开发 → 走「公众号线」；两条线共享第 0 章的 HTTP 基础知识
  3. 每天能投入多少时间？ 每天 1 小时约 8 周走完全程；每天 3 小时约 3 周

课程全景 ​

阶段小程序线（11 章）公众号线（8 章）
🟢 入门第 0-3 章：环境、注册、WXML/WXSS/生命周期、组件与 API第 0-2 章：环境准备、账号认证、自定义菜单
🟡 进阶第 4-6 章：自定义组件、分包加载、网络请求与登录态第 3-4 章：网页授权 OAuth、JSSDK
🟠 实战第 7-8 章：性能优化、云开发完整案例第 5-6 章：消息与素材接口、模板消息
🔴 精通第 9-10 章：跨端方案对比、上线审核全流程第 7 章：完整实战项目

学习建议 ​

  1. 每章按固定顺序读：漫画开场 → 术语卡 → 概念讲解 → 动手实践 → 练习题
  2. 一定要动手：跟做型练习完成后，再尝试修改型和创作型
  3. 遇到报错先查「常见坑」：本章报错大多已在文末列出解法
  4. 卡住超过 30 分钟：回到上一章的「你应该看到什么」逐条核对环境
